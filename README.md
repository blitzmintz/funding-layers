# funding layer simulator
this program shows how money gets allocated to different "funding layers" in a multi-layer banking setup related to an insurance policy.
firstly, enter your layer limits - leave the field/s blank to give a limit of 0 - and an aggregate stop loss amount.

you can add payments and recoveries (all amounts should be positive when typed in!) and see how the transaction is applied against the layer limits. payments will add, recoveries will deduct.
